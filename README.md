**项目简介**： 面向直播场景的完整业务平台，围绕直播间长连接推送、用户中台、分库分表、高并发带货库存、活动互动等核心模块，实现高可用、低延迟的直播业务能力
**职责描述**：
1.负责高性能消息系统设计，基于 **Netty 自研**直播间长连接消息推送系统，支持**高并发下的低延迟通讯**；使用 **RocketMQ** 实现异步消息分发，Router 服务按用户连接路由，**自研 ACK 机制**支持消息失败自动重试。
2.设计**分布式 ID 生成方案**，引入美团 Leaf 号段模式分布式 ID 生成系统，通过**本地缓存 ID 段 + 异步预加载方式**，大幅减少数据库访问频率，提升系统整体性能。
3,参与用户中台服务与分库分表实现，用户数据采用 **ShardingJDBC** 分表方案，结合 MySQL 主从读写分离架构，优化核心查询性能，提升数据访问效率。
4.主导**带货库存高可用处理模块开发**，商品库存数据缓存至 Redis，结合定时任务同步 DB 确保数据一致性；采用 Lua 脚本在 Redis 中原子性扣减库存，彻底解决超卖问题；通过 RocketMQ 延迟消息处理用户未支付订单超时场景，自动回滚库存保障数据准确。
5.设计直播间礼物打赏、PK 对战、红包雨活动的**高并发处理机制，结合多级缓存架构**，保障高并发场景下的系统稳定性与吞吐量。
6.实现基于 Redis 的**限流组件**，采用**缓存空值、延迟双删、随机过期**等方案，解决**缓存穿透、击穿、雪崩问题**，保证 Redis 双写一致性。
